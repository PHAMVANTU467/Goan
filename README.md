Dự án giao diện GOAN với gam màu **#33CCFF -> #99FFFF kết hợp Xanh dương & Trắng**, tích hợp đầy đủ danh mục hình ảnh sản phẩm thực tế và liên kết luồng Đăng nhập ➔ Bán hàng (Point of Sale).

---

## 🌟 Tính năng chính

- 🔐 **Xác thực người dùng:** Giao diện đăng nhập chuẩn mực cho nhân viên và thu ngân.
- 🛒 **Giao diện POS bán hàng:** Danh mục món ăn trực quan, chọn món nhanh, tính tổng tiền tự động.
- 🧾 **Hóa đơn & Thanh toán:** Hỗ trợ xem lại hóa đơn và in phiếu thanh toán.
- ⚡ **Tối ưu tốc độ:** Backend Express.js nhẹ nhàng, phản hồi nhanh chóng.

---

## 🚀 Cài đặt & Chạy cục bộ

```bash
# 1. Cài đặt dependencies
npm install

# 2. Khởi động server
npm start
```
Truy cập tại: `http://localhost:3000`
